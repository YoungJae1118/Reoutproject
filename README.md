# 🎬 FilmPass

## 1. 프로젝트 소개
영화 예매 시스템 - **FilmPass**  
FilmPass는 고객들에게 빠르고 안정적인 영화 티켓 예매 경험을 제공하고,  
고객들이 원하는 영화를 즐길 수 있도록 도와주는 영화 관람 티켓팅 전문 어플리케이션입니다.

👉 (추후 삽입 예정)

## 3. 주요 기능
- 영화 등록 / 수정 / 삭제 (관리자)
- 영화 검색 / 목록 / 상세 조회
- 상영 일정 관리 및 좌석 자동 생성
- 예매 및 결제
- 리뷰 작성 / 수정 / 삭제
- JWT 기반 인증 및 권한 관리 (USER / ADMIN)
- Redis 캐시를 활용한 빠른 조회 성능
